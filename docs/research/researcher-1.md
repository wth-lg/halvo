## Summary
- **Names.** "Prime-Intelligence" resolves to Prime Intellect, Inc. (primeintellect.ai), a compute, RL-training and inference company: open-source trainer prime-rl (Apache-2.0), RL-environment library verifiers (MIT), Environments Hub, Prime Sandboxes, Prime Inference, the INTELLECT model series (INTELLECT-3, 106B MoE, 2025-11-26) and, since 2026-08-05, Prime Agent. It raised a $15M seed (2025-02-28) and a $130M Series A (2026-07-08), and says it has been "scaling RLM training" (findings #7, #32, #55, #49, #26, #30, #37). "Prime-agent" resolves to Prime Agent, Prime Intellect's MIT-licensed, open-source coding and long-running-task harness built on the Recursive Language Model abstraction plus a "Continual Harness" (prompt notes, memories, skills, sub-agent specs edited from the agent's own trajectory; model weights never change). It is a harness, not a model and not a training framework. Rewritten in Rust on 2026-10-09 with native Windows support in beta; latest stable release v0.10.2 on 2026-10-28; its models.json parser accepts a custom provider with a local base URL (findings #1, #14, #21, #28, #16, #13).
- **The paper line.** Recursive Language Models, arXiv 2512.24601, Alex L. Zhang, Tim Kraska, Omar Khattab; v1 2025-12-31, v3 2026-05-11; the authors' repo calls it a NeurIPS 2026 paper. Origin: Zhang and Khattab's blog post of 2025-10-15. Mechanism: the long prompt is a variable in a Python REPL; the root model sees only constant-size metadata, writes code that calls `llm_query` (depth 1) or `rlm_query` (depth 2 and above) on snippets, and stops when it sets a final-answer variable; recursion depth is capped (depths 0 to 3 evaluated) and an iteration cap exists. Follow-ups that extend it: Prime Agent (2026-08-24, subagents as async function calls in a persistent IPython kernel, stopping by model choice or turn, token and wall-clock budgets), Recursive Agent Harnesses (2026-06-11, the recursive unit is a full tool-using agent spawned by a generated script), Chained RLM (2026-08-05, a sequence of fresh roots that inherit a summary and a blackboard, not the history), SRLM (2026-03-07, self-reflection picks among candidate context programs), Self-Evaluating Recursive Agents (2026-10-04, trains the policy to write rubrics for child subtasks), RLMOpt (2026-08-11, RLM as a prompt-optimizer search policy), and a theory paper on why context isolation generalizes out of domain (2026-07-23). Findings #38, #51, #48, #21, #34, #27, #43, #17, #24, #29.
- **Implementations.** Official: alexzhang13/rlm (MIT, Python, pip `rlms`, last commit 2026-11-04, latest release v0.1.3 on 2026-06-26, 6 releases in 12 months, 38 open issues; local, ipython, docker, modal, prime, daytona, e2b sandboxes; vLLM recommended for local models) and the superseded alexzhang13/rlm-minimal (last commit 2026-01-07, evidence repo-health.txt). Product: Prime Agent (MIT, Rust, 60 releases in 12 months, 14 open issues, 22,626 stars; custom providers with a local base URL in models.json). Released weights: mit-oasys/rlm-qwen3-8b-v0.1 (MIT, 8B, BF16, page last modified 2026-02-20). Community reimplementations (fast-rlm, rlm-go, hampton-io/RLM) have no releases in 2026 after spring or no releases at all (evidence repo-health.txt). Findings #6, #1, #16, #45 and the Options section.
- **Other self-improving-agent work, primary-source backed.** Frozen-weights harness evolution: ReasoningBank (memory of reasoning strategies, v2 2026-03-16, #40), EvoLib test-time learning library (v3 2026-11-06, #4), SkillOS (RL-trained skill curator, 2026-05-07, #39), RSIAgent (training-free memory construction, OSWorld-v2, 2026-09-18, #18), Hierarchical Self-Improvement (frozen DeepSeek-V4-Flash-Preview, BALROG, 2026-08-09, #25, code #22), Self-Evolving Agent Harness (theory, 2026-10-13, #12). Code self-modification with search: Darwin Godel Machine (ICLR 2026, SWE-bench 20.0% to 50.0%, about USD 22,000 and 2 weeks per run, #41, code #53), Huxley-Gödel Machine (2025-10-29, #50, code #46), Hyperagents (v2 2026-11-01, #9), Group-Evolving Agents (2026-02-04, 71.0% SWE-bench Verified, #47). Weight updates: SEAL (self-generated finetuning data, 2025-09-18, #52), Agent Learning via Early Experience (2026-05-24, #35), ClawLoop (2026-10-09, #15), SAGE skill-library RL (2026-03-10, #42). AlphaEvolve (white paper from Google, 2025-06-16, #54) is hosted and unreleased; OpenEvolve (Apache-2.0, v0.4.1 2026-11-02, #3) is the open reimplementation. Surveys: Self-Improvements in Modern Agentic Systems (2026-07-14, 97 pages, #31, list #5) and Safety in Self-Evolving Agents (2026-09-08, #20). Benchmarks: SelfImprove-Bench (#8), EvoAgentBench (#33), Evo-Memory (#36). Negative or cautionary results from 2026-10: self-evolving agents repair observed failures but rarely generalize (2026-10-16, #11); self-modification trades stability for plasticity under task drift (2026-10-19, #10); 197 of 600 capability-improving self-modifications were not safely reversible (EvoUndo, #19). All benchmark numbers are self-reported by the authors unless a row says otherwise.
- **Compute, model size, data, and reproduction (standalone paragraph for lane 2).** Inference-only RLM is a scaffold around any chat model plus a code-execution environment; the official library runs an in-process local REPL by default and recommends vLLM for a local model (#6). The paper's own runs used hosted GPT-5 and Qwen3-Coder-480B-A35B through APIs at an average API cost of $0.11 to $0.99 per query for GPT-5 at depth 1 (authors' Table 1, high variance: Qwen3-Coder depth 2 on OOLONG cost $1.03 ± $1.65; #38, evidence webfetch-notes.md). The only independent reproduction (Daren Wang, The Chinese University of Hong Kong, 2026-03-03, #44) ran the client on a macOS laptop CPU with hosted DeepSeek v3.2 and Kimi K2: it confirmed the depth-1 OOLONG gain for DeepSeek v3.2 (0.0% to 42.1%, 20 samples, one run) but found Kimi K2 fell from 86.6% to 60.0%, simple retrieval (S-NIAH) fell from 100% to 85% at depth 1 and 70% at depth 2, and per-query latency rose from 3.6 s to 89.3 s (depth 1) and 344.5 s (depth 2). Training: the only released RLM-native model, RLM-Qwen3-8B-v0.1 (MIT, 8B, BF16, four safetensors shards, #45), was rejection-fine-tuned on about 1,000 filtered trajectories distilled from Qwen3-Coder-480B-A35B on LongBenchPro tasks, batch 64, 300 steps, 48 H100 hours (authors' statement, not reproduced, #38); a separate RL run trained Qwen3-4B-Instruct with verifiable rewards on MRCRv2, compute not stated. A third party (SEER, 2026-08-16, #23) evaluated the released 8B checkpoint on seven LongBench QA tasks and measured 42.60 versus 52.25 for plain Qwen3-8B under its own protocol, so the paper's 28.3% median gain has not been independently confirmed on the paper's tasks and has been contradicted on shorter ones. Prime Agent changes no weights; every reported Prime Agent number came from hosted frontier models (Opus 5, GPT-5.6 Sol, GLM-5.2, Kimi K3), and the ARC-AGI-3 95.5% is Prime Intellect's own run (#21, #28); the ARC Prize leaderboard page fetched 2026-11-09 names neither Prime Agent nor Prime Intellect (#2). Prime Intellect's own RLM experiments (2026-01-01, #48) were 50 hosted rollouts per setting, no training. Laptop implication: an inference-only RLM over a local 8B model fits a 32 GB laptop in quantized form in principle (a quantized variant is listed on Hugging Face, no evaluation of it found); every training result in this line was produced on H100 or H200 class GPUs; every self-improving-agent result above that changes weights, and every DGM-family run, needs cluster or API spend far beyond a laptop.

## Options for the planner
Hard requirements, from the brief and the product constraints, checked per option as R1 to R5:
- R1 language-agnostic: the option is a method or a component the product can call from any language, not a binding to one language.
- R2 laptop: runs on a consumer macOS and Windows laptop.
- R3 nothing captured leaves the machine: inference and learning can run against a local model, and the component sends nothing home by default.
- R4 license: a license that does not block opening the repo later (a repo with no license file fails).
- R5 non-technical end user: the end user never sees a terminal, a prompt or a model choice, so the option must be embeddable or drivable by the product; a tool the user operates fails as shipped.
Tier 1 holds options that meet R1 to R5 (unknowns stated). Tier 2, "conditional", holds options that meet R1, R2 and R4 but fail or leave unverified R3 or R5 as shipped; the planner may take one only with the named condition. Within a tier, ranking follows the recency rules: date of current form first, then stated demotions.

Tier 1

1. **Frozen-weights memory and skill libraries: EvoLib (v3 2026-11-06), RSIAgent (2026-09-18), ReasoningBank (v2 2026-03-16), Hierarchical Self-Improvement (2026-08-09)**
   - What: the agent keeps a library of memories, insights or skills distilled from its own trajectories and retrieves them; no parameter updates. HSI additionally rewrites the harness code per task family with a frozen model.
   - R1: meets (methods; no shipped package found for EvoLib, RSIAgent or ReasoningBank).
   - R2: meets in principle; the cost is model calls, which can be local. Unknown quality with small local models: all four papers used hosted frontier or large open models.
   - R3: meets; the mechanism is prompt, memory and skill state on disk plus model calls, nothing in the method phones home.
