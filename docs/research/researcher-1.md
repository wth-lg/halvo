## Summary
- **Names.** "Prime-Intelligence" resolves to Prime Intellect, Inc. (primeintellect.ai), a compute, RL-training and inference company: open-source trainer prime-rl (Apache-2.0), RL-environment library verifiers (MIT), Environments Hub, Prime Sandboxes, Prime Inference, the INTELLECT model series (INTELLECT-3, 106B MoE, 2025-11-26) and, since 2026-08-05, Prime Agent. It raised a $15M seed (2025-02-28) and a $130M Series A (2026-07-08), and says it has been "scaling RLM training" (findings #3, #19, #35, #37). "Prime-agent" resolves to Prime Agent, Prime Intellect's MIT-licensed, open-source coding and long-running-task harness built on the Recursive Language Model abstraction plus a "Continual Harness" (prompt notes, memories, skills, sub-agent specs edited from the agent's own trajectory; model weights never change). It is a harness, not a model and not a training framework. Rewritten in Rust on 2026-10-09 with native Windows support in beta; latest stable release v0.10.2 on 2026-10-28 (findings #1, #5, #13, #17).
- **The paper line.** Recursive Language Models, arXiv 2512.24601, Alex L. Zhang, Tim Kraska, Omar Khattab (MIT CSAIL); v1 2025-12-31, v3 2026-05-11; the authors' repo calls it a NeurIPS 2026 paper. Origin: Zhang and Khattab's blog post of 2025-10-15. Mechanism: the long prompt is a variable in a Python REPL; the root model sees only constant-size metadata, writes code that calls `llm_query` (depth 1) or `rlm_query` (depth 2 and above) on snippets, and stops when it sets a final-answer variable; recursion depth is capped (depths 0 to 3 evaluated) and an iteration cap exists. Follow-ups that extend it: Prime Agent (2026-08-24, subagents as async function calls in a persistent IPython kernel, stopping by model choice or turn, token and wall-clock budgets), Recursive Agent Harnesses (2026-06-11, the recursive unit is a full tool-using agent spawned by a generated script), Chained RLM (2026-08-05, a sequence of fresh roots that inherit a summary and a blackboard, not the history), SRLM (2026-03-07, self-reflection picks among candidate context programs), Self-Evaluating Recursive Agents (2026-10-04, trains the policy to write rubrics for child subtasks), RLMOpt (2026-08-11, RLM as a prompt-optimizer search policy), and a theory paper on why context isolation generalizes out of domain (2026-07-23). Findings #8, #9, #14, #16, #20, #23, #25, #26, #31.
- **Implementations.** Official: alexzhang13/rlm (MIT, Python, pip `rlms`, last commit 2026-11-04, latest release v0.1.3 on 2026-06-26, 6 releases in 12 months, 38 open issues; local, ipython, docker, modal, prime, daytona, e2b sandboxes; vLLM recommended for local models) and the superseded alexzhang13/rlm-minimal (last commit 2026-01-07). Product: Prime Agent (MIT, Rust, 60 releases in 12 months, 14 open issues, 22,626 stars). Released weights: mit-oasys/rlm-qwen3-8b-v0.1 (MIT, 8B, BF16). Community reimplementations (fast-rlm, rlm-go, hampton-io/RLM) have no releases in 2026 after spring or no releases at all. Findings #1, #24, #33, #38, #39, #40 and the Options section.
- **Other self-improving-agent work, primary-source backed.** Frozen-weights harness evolution: ReasoningBank (Google, memory of reasoning strategies, v2 2026-03-16), EvoLib test-time learning library (Microsoft, v3 2026-11-06), SkillOS (Google, RL-trained skill curator, 2026-05-07), RSIAgent (training-free memory construction, OSWorld-v2, 2026-09-18), Hierarchical Self-Improvement (frozen DeepSeek-V4-Flash-Preview, BALROG, 2026-08-09), Self-Evolving Agent Harness (theory, 2026-10-13). Code self-modification with search: Darwin Godel Machine (ICLR 2026, SWE-bench 20.0% to 50.0%, about USD 22,000 and 2 weeks per run), Huxley-Gödel Machine (2025-10-29), Hyperagents (v2 2026-11-01), Group-Evolving Agents (2026-02-04, 71.0% SWE-bench Verified). Weight updates: SEAL (self-generated finetuning data, 2025-09-18), Agent Learning via Early Experience (Meta, 2026-05-24), ClawLoop (2026-10-09), SAGE skill-library RL (2026-03-10). AlphaEvolve (Google DeepMind white paper, 2025-06-16) is hosted and unreleased; OpenEvolve (Apache-2.0, v0.4.1 2026-11-02) is the open reimplementation. Surveys: Self-Improvements in Modern Agentic Systems (2026-07-14, 97 pages) and Safety in Self-Evolving Agents (2026-09-08). Negative or cautionary results from 2026-10: self-evolving agents repair observed failures but rarely generalize (2026-10-16); self-modification trades stability for plasticity under task drift (2026-10-19); 197 of 600 capability-improving self-modifications were not safely reversible (EvoUndo). All benchmark numbers are self-reported by the authors unless a row says otherwise. Findings #2, #4, #6, #7, #10, #11, #12, #15, #21, #22, #27, #28, #29, #30, #32, #34, #36, #41.
- **Compute, model size, data, and reproduction (standalone paragraph for lane 2).** Inference-only RLM is a scaffold around any chat model plus a code-execution environment; the official library runs an in-process local REPL by default and recommends vLLM for a local model. The paper's own runs used hosted GPT-5 and Qwen3-Coder-480B-A35B through APIs at an average API cost of $0.11 to $0.99 per query for GPT-5 at depth 1 (authors' Table 1, high variance: Qwen3-Coder depth 2 on OOLONG cost $1.03 ± $1.65). The only independent reproduction (Daren Wang, CUHK, 2026-03-03) ran the client on a macOS laptop CPU with hosted DeepSeek v3.2 and Kimi K2: it confirmed the depth-1 OOLONG gain for DeepSeek v3.2 (0.0% to 42.1%, 20 samples, one run) but found Kimi K2 fell from 86.6% to 60.0%, simple retrieval (S-NIAH) fell from 100% to 85% at depth 1 and 70% at depth 2, and per-query latency rose from 3.6 s to 89.3 s (depth 1) and 344.5 s (depth 2). Training: the only released RLM-native model, RLM-Qwen3-8B-v0.1 (MIT, 8B, BF16, four safetensors shards), was rejection-fine-tuned on about 1,000 filtered trajectories distilled from Qwen3-Coder-480B-A35B on LongBenchPro tasks, batch 64, 300 steps, 48 H100 hours (authors' statement, not reproduced); a separate RL run trained Qwen3-4B-Instruct with verifiable rewards on MRCRv2, compute not stated. A third party (SEER, 2026-08-16) evaluated the released 8B checkpoint on seven LongBench QA tasks and measured 42.60 versus 52.25 for plain Qwen3-8B under its own protocol, so the paper's 28.3% median gain has not been independently confirmed on the paper's tasks and has been contradicted on shorter ones. Prime Agent changes no weights; every reported Prime Agent number came from hosted frontier models (Opus 5, GPT-5.6 Sol, GLM-5.2, Kimi K3), and the ARC-AGI-3 95.5% is Prime Intellect's own run; the ARC Prize leaderboard page fetched 2026-11-09 names neither Prime Agent nor Prime Intellect. Prime Intellect's own RLM experiments (2026-01-01) were 50 hosted rollouts per setting, no training. Laptop implication: an inference-only RLM over a local 8B model fits a 32 GB laptop in quantized form in principle (a quantized variant is listed on Hugging Face, no evaluation of it found); every training result in this line was produced on H100 or H200 class GPUs; every self-improving-agent result above that changes weights, and every DGM-family run, needs cluster or API spend far beyond a laptop.

## Options for the planner
Hard requirements applied: language-agnostic (the option is a method or a harness the product can call, not a language binding), and for each option whether it is laptop-feasible on a consumer Mac or Windows laptop with nothing captured leaving the machine, hosted-only, or unknown. Ranked by the recency rules: current form first, then stated demotions.

1. **Prime Agent v0.10.2 Continual Harness** (2026-10-28)
   - What: MIT harness; agent state H = (prompt notes, sub-agent specs, skills, memories) edited by CRUD operations from the agent's own trajectory, versioned, rollback by ID, base prompt immutable, weights fixed. RLM-style subagents as async Python calls in a persistent IPython kernel. Daemon, schedules, heartbeats, bounded autonomous mode.
   - Fit: language-agnostic as a pattern (the harness itself is Rust, CLI and TUI, not an embeddable library). Laptop-feasible for the harness (macOS, Windows beta since 2026-10-09). Model side: documented providers are subscriptions, API keys and the user's local models.json with provider blocks (README shows a "prime-inference" block); whether a local OpenAI-compatible server is still documented in the Rust build is unknown (the TypeScript-era models.md is gone from the tree). So: harness laptop-feasible, inference hosted unless a local server is wired in, unverified.
   - Tradeoffs: most active project in the lane, Windows support, explicit rollback and provenance; executes model-generated Python with the user's permissions and is "not a security sandbox" (README); the Factorio run shows a learned exploit being saved as a skill; all benchmark claims self-reported; a coding-agent CLI, not a personal-workflow runtime.
   - Health: last commit 2026-11-09, latest release v0.10.2 2026-10-28, releases in last 12 months 60, open issues 14, archived no, license MIT
   - Evidence: findings #1, #8, #15, #19
2. **alexzhang13/rlm v0.1.3 (rlms) inference-only RLM** (2026-06-26; repo active 2026-11-04)
   - What: Python library around any OpenAI-, Anthropic- or router-compatible client; long context as a REPL variable; `llm_query` and `rlm_query`; depth and sub-call limits; local, ipython, docker and cloud sandboxes; optional RL training harness into prime-rl.
   - Fit: language-agnostic as a pattern (the product would call it as a sidecar or reimplement the loop; the loop is small, rlm-minimal is "gist-like"). Laptop-feasible with a local model served by vLLM or any OpenAI-compatible local server; the released RLM-Qwen3-8B weights are MIT and 8B.
   - Tradeoffs: gives long-context processing (the 7 to 14 day capture stream), not per-user learning; independent reproduction shows depth 2 and simple tasks degrade and latency grows 25x to 100x; the 8B checkpoint underperformed its base on shorter QA in a third-party test.
   - Health: last commit 2026-11-04, latest release v0.1.3 2026-06-26, releases in last 12 months 6, open issues 38, archived no, license MIT
   - Evidence: findings #30, #36, #16, #39, #49
3. **Frozen-weights memory and skill libraries: EvoLib (2026-11-06), RSIAgent (2026-09-18), ReasoningBank (2026-03-16), Hierarchical Self-Improvement (2026-08-09)**
   - What: the agent keeps a library of memories, insights or skills distilled from its own trajectories and retrieves them; no parameter updates. HSI additionally rewrites the harness code per task family with a frozen model.
   - Fit: language-agnostic (methods, no shipped package found for EvoLib, RSIAgent or ReasoningBank; HSI code at TailinZhou/hsi, 14 stars, no license). Laptop-feasible in principle: the cost is model calls, which can be local. Unknown quality with small local models; all papers used hosted frontier or large open models.
   - Tradeoffs: closest match to "keeps improving itself on the tasks it already runs"; the 2026-10 negative results (plasticity versus stability under drift; repair without generalization) and the EvoUndo recoverability result apply directly.
   - Health (HSI only): last commit 2026-08-23, latest release none, releases in last 12 months 0, open issues 1, archived no, license none
   - Evidence: findings #2, #12, #33, #17, #6, #7, #13
4. **OpenEvolve v0.4.1** (2026-11-02), AlphaEvolve-style evolutionary program search
   - What: Apache-2.0 Python loop that evolves code against an evaluator with LLM mutations.
   - Fit: language-agnostic as a tool; laptop-feasible with a local model in principle, but designed for algorithm optimization against a programmatic evaluator, not for personal workflow agents. Demoted for fit to the product, not for health.
