## Summary
- **How comparable desktop apps sell and meter.** The current pattern (Cursor, Warp, GitHub Copilot, Claude) is a flat monthly plan that includes a pool of model usage, plus prepaid credit or pay-as-you-go "extra usage" at API list price once the pool is gone, with a user-set monthly spend cap on the extra usage. Windsurf's pricing page is now Devin-branded with extra usage at API pricing (#8). Cursor now sells through "The X Subscription" with a weekly usage pool and a "monthly additional usage limit" (#1, #2). Copilot bills "AI credits" at $0.01 per credit beyond the plan allowance (#3) and GitHub budgets block further usage when a budget with "Stop usage" is exhausted (#4). Claude lets a subscriber turn on usage credits and set a monthly spend limit or "unlimited"; usage stops at the limit (#6). Warp includes a dollar amount of agent usage at API rates and a team-wide spend cap on Max (#7). Setapp sells "AI credits" bundled with the app subscription (#10). None of these products exposes a weekly cap to consumers; the cap unit is monthly, the reset of included usage is weekly or per 5 hours. ChatGPT pricing could not be fetched (HTTP 403 for curl and the fetch tool); see Unknowns.
- **Payment providers for a desktop app.** Every provider surveyed opens payment in the system browser on a hosted page; none offers a desktop-native SDK. Stripe Checkout redirects to a Stripe-hosted page and returns to an HTTPS success page you host (#16, #17), supports Link, Apple Pay and Google Pay with no extra configuration on the hosted page (#18, #19), and costs 2.9% + 30¢ per card charge plus 0.7% of Billing volume (#14, #15). Merchant-of-record options that take on tax: Paddle 5% + 50¢ (#24), Lemon Squeezy 5% + 50¢ and now routed onto Stripe Managed Payments (#25), Polar 5% + 50¢ free tier or $20/mo at 3.8% + 40¢ (#28), and Stripe Managed Payments itself, fee not stated on the page (#23). RevenueCat is free under $2,500 monthly tracked revenue then 1%, and on the web it wraps Stripe or Paddle rather than replacing them (#26, #27). Store billing: Apple requires in-app purchase for subscriptions only for apps submitted to the App Store (#30); Developer ID distribution outside the Mac App Store carries no commission (#31); Microsoft Store policy 10.8.1 requires Store purchase APIs only for games and Xbox, and non-game apps may use their own commerce and keep 100% (#33, #34).
- **Smallest backend.** Three services cover accounts, billing and metering with no capture data: an auth layer (Better Auth self-hosted, MIT, passkey and magic-link plugins, #38; or hosted Clerk, Supabase, WorkOS, Auth0, all free at 100 and 10,000 users, #35 to #37), Stripe Checkout plus Billing for the card and the subscription (#14 to #22), and an LLM gateway that holds the vendor keys and enforces the per-user cap: Vercel AI Gateway (zero markup, $5/month free credit, budgets per team, project, API key and user, HTTP 402 when exceeded, #42, #43), LiteLLM self-hosted (MIT outside enterprise/, per-key max_budget with budget_duration, but the budget fails open without a database, #41), or OpenRouter (no inference markup, 5.5% fee on credit purchases, per-key limits with daily, weekly and monthly resets, #44, #45). Hosting for the thin API: Fly.io from $2.19/month per machine (#48), Cloudflare Workers free or $5/month (#49), Railway $1 to $5/month (#50). Cost arithmetic is in Options.
- **Fewest prompts.** Hosted Stripe Checkout with Link and Apple Pay or Google Pay gives a returning Link user a one-tap card entry; Stripe reports a 14% average returning-user conversion lift and "40% faster" payment for OpenAI customers (self-reported marketing numbers, setup not stated, #18). Stripe trials can start without collecting a payment method, but metered items are not supported on such trials (#22), so a trial that meters model usage needs the card up front or a prepaid credit grant (#21). The cap can be a default (for example $50/month) set server-side with a one-tap change, which is how Claude ("Adjust limit" or "Set to unlimited", #6) and Vercel default budgets (#43) work. No provider page gives a completion-rate number for cap entry.
- **Metering record and cap-hit behaviour.** The gateway records per request: account or key id, timestamp, model, prompt and completion tokens, computed cost, and request tags; Polar's LLM strategy emits exactly prompt and completion tokens per model call (#29), LiteLLM's spend logs are per key, user, team and tag (#41), Stripe meter events carry a customer id, a value and a timestamp and are aggregated asynchronously (#20). No content is needed for any of these. At the cap: OpenAI returns HTTP 429 with a spend-limit code and says enforcement is not instantaneous (#51); the Claude API stops requests at the monthly cap (#52); Vercel rejects with 402 after the request that crosses the line completes (#43); GitHub blocks until the next cycle or a raised budget (#4); Cursor offers wait, top-up or upgrade (#1); Claude consumer usage simply stops (#6). The common pattern is: the in-flight request finishes, the next one is refused, the user is told to raise the cap or wait for the reset.

## Options for the planner
Hard requirements applied: no captured or derived end-user data on the backend; the desktop app never holds a vendor API key; free or low-cost tier; license compatible with a future MIT release. Cost arithmetic assumes a $20/month plan and a $50/month model-usage cap, 12 charges a year, and uses the fees in Findings; model spend itself is pass-through at list price in every case.

**Payment and subscription**
1. **Stripe Checkout + Stripe Billing** (current form: API version 2026-10-28 on the Checkout Session reference, fetched 2026-11-09)
   - What: hosted Checkout page opened in the system browser, Link, Apple Pay and Google Pay on by default, subscriptions and meters in Billing, customer portal for cancellation.
   - Fit: meets all four. Backend receives only the Stripe customer id, subscription state and meter events (customer id, value, timestamp). Tax is extra (Stripe Tax or Managed Payments).
   - Tradeoffs: lowest fee and the deepest usage-billing features; you are the merchant of record unless you add Managed Payments; the return from the hosted page to a desktop app needs an HTTPS bounce page or session polling (#17).
   - Cost: 100 users: 100 × ($20 × 2.9% + $0.30) = $88 cards + 0.7% × $2,000 = $14 Billing = about $102/month. 10,000 users: $8,800 + $1,400 = about $10,200/month. Managed service, no repo health line.
   - Evidence: #14 to #23.
2. **Polar** (Starter free tier, Pro $20/month; repo pushed 2026-11-08)
   - What: merchant of record with hosted checkout, customer portal, usage meters and an LLM token ingestion SDK; Apache-2.0 source.
   - Fit: meets all four; tax handled; the LLM strategy sends token counts only.
   - Tradeoffs: tax and disputes off your plate; fee about 2× Stripe at small volume; younger than Stripe.
   - Cost: Starter: 100 users: 100 × ($1.00 + $0.50) = $150/month; 10,000: $15,000/month. Pro: $20 + 100 × ($0.76 + $0.40) = $136/month; 10,000: $20 + $11,600 = $11,620/month.
   - Health: last commit 2026-11-08, latest release @polar-sh/better-auth@2.1.3 2026-10-30, releases in last 12 months 49, open issues 69, archived no, license Apache-2.0.
   - Evidence: #28, #29.
3. **Stripe Managed Payments** (docs page fetched 2026-11-09)
   - What: Stripe as merchant of record on top of Checkout; Lemon Squeezy now routes onto it.
   - Fit: meets all four. Tradeoffs: fee not on the public page (Unknowns); no Connect.
   - Evidence: #23, #25.
4. **Paddle** and **Lemon Squeezy** (5% + 50¢ each)
   - What: merchant of record with hosted or overlay checkout. Fit: meets all four. Cost: 100 users $150/month, 10,000 users $15,000/month, same as Polar Starter with no cheaper tier.
   - Evidence: #24, #25.
5. **RevenueCat** (free under $2,500 MTR)
   - What: subscription state layer over Stripe or Paddle; adds nothing a desktop-only product needs unless it also ships on iOS or Android. Cost: $0 at 100 users; 1% × $200,000 = $2,000/month at 10,000 users on top of the engine's fees.
   - Evidence: #26, #27.

**Auth** (all meet the hard requirements; ranked by what the backend must receive)
1. **Better Auth v1.7.18** (2026-11-05): self-hosted, MIT, passkey and magic-link plugins, Stripe and Polar plugins exist. Receives email and credential only. Cost $0 licence; runs inside the API host. Health: last commit 2026-11-09, latest release v1.7.18 2026-11-05, releases in last 12 months 100, open issues 445, archived no, license MIT. Evidence #38.
2. **Clerk** (Hobby free, 50,000 MRU), **Supabase Auth** (free 50,000 MAU, project pauses after a week idle; Pro $25/month), **WorkOS** (free to 1 million users), **Auth0** (free to 25,000 MAU). All $0 at 100 and 10,000 users; Auth0 is the first to charge, above 25,000 MAU. Evidence #35 to #37.

**LLM gateway and cap enforcement** (the app gets a per-user token from the backend; the gateway holds the vendor keys)
1. **Vercel AI Gateway** (per-user budgets 2026-08-31): zero markup, $5/month free credit, budgets per user with daily, weekly or monthly reset and 402 when exceeded. Receives the prompt in transit (it is the inference path) but stores no content by default; lane 5 owns retention terms. Cost: 100 users at a full $50 cap = up to $5,000/month pass-through, $0 gateway fee; 10,000 users up to $500,000/month, $0 fee. Managed service. Evidence #42, #43.
2. **LiteLLM v1.108.3** (2026-11-07): self-hosted, MIT outside enterprise/ (evidence litellm-license.txt), per-key max_budget and budget_duration, spend logs per key and tag. Needs Postgres or the budget fails open (#41). Cost: one Fly.io 1 GB machine $6.70/month plus a Postgres machine of the same size, about $14/month at 100 users; at 10,000 users budget for 2 to 4 machines, about $30 to $60/month, pass-through model spend unchanged. Health: last commit 2026-11-09, latest release v1.108.3 2026-11-07, releases in last 12 months 100, open issues 1,644, archived no, license MIT (enterprise/ excluded). Evidence #41.
3. **OpenRouter** (fetched 2026-11-09): no inference markup, per-user keys with limits and resets, one vendor relationship for many models. Cost: 5.5% on credit purchases: 100 users at $50 = $275/month overhead; 10,000 users = $27,500/month. Evidence #44, #45.
4. **Cloudflare AI Gateway** (2026-11-02): free core features, BYOK; no per-user budget feature found on the pages fetched. Evidence #46.
5. **OpenMeter v1.0.0-beta.236** (2026-10-09): Apache-2.0 metering plus Stripe invoicing if LiteLLM's own spend table is not enough; still beta.
