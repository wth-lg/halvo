# researcher #7: Local privacy engineering
STATUS: ISSUES
now: 2026-11-09    stale cutoff: 2026-05-09    lane: 7

## Summary
- **Key custody (sub-question 1).** macOS: a key can live in the Secure Enclave and be used for signing or unwrapping with no prompt when its access control has only the privateKeyUsage flag; adding biometryAny or userPresence makes every use prompt for Touch ID or the password (#4). Secure Enclave keys require the data protection keychain, which exists only in a user login context, so a launchd daemon cannot use it and the capture process must be a signed, bundled LaunchAgent that starts after login (#3). Apple documents kSecAttrAccessibleAfterFirstUnlock for background work, isolates items per app through code-signed access groups, and encrypts each row with its own AES-256-GCM key (#9). Windows: CryptProtectData (DPAPI) decrypts with no prompt for any process running under the same logon credential on the same machine, so a per-user startup task gets it after logon; the LOCAL_MACHINE flag lets every user on the machine decrypt, so it is the wrong scope (#20). DPAPI-NG adds descriptors for domain groups, web credentials, LOCAL=user and LOCAL=machine and brings nothing extra for a single unattended laptop (#30, #33). TPM-bound keys come from the Microsoft Platform Crypto Provider, and a TPM key can be made unusable outside the TPM and bound to boot measurements (#12, #15). Windows Hello keys are released only after a PIN or biometric gesture, and Recall's keys are tied to Hello Enhanced Sign-in Security, so a Hello-gated key cannot serve an unattended process (#17, #22). VBS enclaves are a developer-usable trusted execution environment on Windows 11 build 26100.2314 or later (#24).
- **Shipping apps (sub-question 2).** Microsoft Recall: snapshots and the vector index are always encrypted, keys sit in the TPM tied to the user's Hello ESS identity and are usable only inside a VBS enclave, Hello confirmation is required before launch and before reading snapshots, and other users, admins and Microsoft cannot read them (#22, #25). In April 2026 a researcher showed that the unprotected timeline host process can be injected after the user has authenticated, and Microsoft called it "not a vulnerability" (#13, #14). Apple Intelligence runs many models on device and sends the rest to Private Cloud Compute, which Apple says stores nothing and which has a published security guide and research environment (#10, #28). 1Password encrypts with AES-GCM-256 and derives keys with PBKDF2-HMAC-SHA256 from the account password plus a 128-bit Secret Key kept on the device (#39). Screenpipe stores everything locally, self-reports 5 to 20 percent CPU and about 30 GB per month at 1 fps, and is under a commercial source-available license since 2026 (#2, #40). Rewind shut down in December 2025 after Meta bought Limitless; its storage numbers survive only in reviews (#23).
- **Verifiable deletion (sub-question 3).** SQLite leaves deleted content in place unless secure_delete is on, and FTS5 keeps deleted index entries until merges unless its secure-delete option is set, which the SQLite docs say otherwise lets anyone with database access reconstruct deleted rows (#41, #42). A checkpoint does not truncate the WAL file unless journal_size_limit is set or the checkpoint mode is TRUNCATE, which zeroes the file length (#43, #44). sqlite-vec reclaims deleted vector space only when a whole chunk empties and had a data leak through undeleted DiskANN neighbor vectors fixed in a 2026 alpha, and Lance records deletions as position lists in deletion files next to the data files, so both need compaction before "deleted" means "gone from disk" (#5, #6, #37). Apple's crypto-erase model wraps the file system key with an effaceable key whose erasure makes all files cryptographically inaccessible, and NIST SP 800-88 Rev. 2 (September 2025) is the current standard that lists cryptographic erase (#32, #19). No primary source was found for APFS or NTFS TRIM timing, so per-file overwrite cannot be relied on and crypto-shredding (one key per capture segment, destroyed on delete) is the only deletion the app can verify itself. Crash reports: Windows sends no crash dumps at the Required diagnostic level and full or triage memory dumps at Optional; Apple says personal data is removed from analytics reports before they are sent and sharing is opt-in (#21, #35).
- **Cost bounds (sub-question 4).** Published numbers are vendor estimates, not measurements: Screenpipe README 5 to 20 percent CPU and 0.5 to 3 GB RAM depending on hardware and settings (#2), Screenpipe FAQ about 30 GB per month at 1 fps with frames the largest contributor (#40), Recall storage caps default to 25 GB on a 256 GB drive, 75 GB on 512 GB and 150 GB on 1 TB or more, with user-settable limits (#16). No source gave battery share. OS facilities: macOS App Nap lowers priority and throttles timers and I/O for apps not doing user work, and Apple tells apps to declare lengthy work with NSProcessInfo activities rather than rely on it (#45, #46); BGTaskScheduler is not available on native macOS (#47). Windows assigns Low QoS to invisible windowed apps and Utility QoS to background services on battery, and a process can opt into EcoQoS through SetProcessInformation so it always runs at efficient frequency on efficient cores (#26, #27).
- **Libraries (sub-question 5).** SQLCipher 4.20.0 (2026-10-27, BSD-3-Clause) for page-encrypted SQLite (#1, #7); libsodium 1.0.22 (ISC) and age 1.3.2 (BSD-3-Clause) for file and stream encryption (#8, #11); LanceDB 0.41.0 (Apache-2.0) or sqlite-vec 0.1.9 (MIT or Apache-2.0) for local vectors, both with deferred physical deletion (#5, #6, #37, #38). No OS API for a user-visible inventory of an app's stored data was found on either platform; Windows ApplicationData only reaches the calling app's own folders (#18). See Options and Unknowns.

## Options for the planner
Hard requirements: macOS and Windows; unattended operation after reboot; license compatible with a repo that may later be MIT. Only libraries are ranked; OS key custody facilities are listed after them because they are not packages.

1. **SQLCipher 4.20.0** (2026-10-27)
   - What: SQLite fork with whole-file AES-256 page encryption, HMAC tamper detection and memory sanitization.
   - Fit: meets all three (C library builds on both platforms; key supplied by the app at open; BSD-3-Clause).
   - Tradeoffs: one key for the whole database, so per-segment crypto-shredding needs a separate layer; self-reported 5-15 percent overhead; secure_delete and FTS5 secure-delete still apply inside the encrypted file.
   - Health: last commit 2026-10-26, latest release v4.20.0 2026-10-27, releases in last 12 months 11, open issues 9, archived no, license BSD-3-Clause.
   - Evidence: findings #1, #7.
2. **libsodium 1.0.22** (2026-04-09)
   - What: portable crypto library (secretstream, AEAD, key derivation) for encrypting capture segments with per-segment keys.
   - Fit: meets all three (C, bindings for every candidate app language, ISC).
   - Tradeoffs: a library, not a format; the app owns key wrapping, rotation and destruction.
   - Health: last commit 2026-11-08, latest release 1.0.22 2026-04-09, releases in last 12 months 2, open issues 0, archived no, license ISC.
   - Evidence: finding #11.
3. **age v1.3.2** (2026-08-29)
   - What: file encryption format and Go library with X25519 and scrypt recipients and post-quantum support.
   - Fit: meets license and platform requirements; unattended use is fine with a stored identity file. Demoted below libsodium because the library is Go only, so a non-Go app needs the CLI or a port that this lane did not check.
   - Health: last commit 2026-08-29, latest release v1.3.2 2026-08-29, releases in last 12 months 3, open issues 17, archived no, license BSD-3-Clause.
   - Evidence: finding #8.
4. **LanceDB v0.41.0** (2026-10-29)
   - What: embedded columnar vector store with versioned tables.
   - Fit: meets all three (Rust core with Python and Node bindings; Apache-2.0).
   - Tradeoffs: deletes are deletion files until compaction, and old versions keep the data until cleaned up; heavier dependency than sqlite-vec.
   - Health: last commit 2026-11-08, latest release v0.41.0 2026-10-29, releases in last 12 months 100 or more, open issues 471, archived no, license Apache-2.0.
   - Evidence: findings #37, #38.
5. **sqlite-vec v0.1.9** (2026-03-31)
   - What: SQLite extension for vector search inside the same encrypted database.
   - Fit: meets all three (C extension; MIT or Apache-2.0).
   - Tradeoffs: pre-1.0; deleted vectors are reclaimed only when a chunk empties, and a 2026 alpha fixed data leaking through undeleted DiskANN neighbor vectors; last commit 2026-05-18, so activity is lower than LanceDB. The photostructure fork adds an optimize command but has 6 stars.
   - Health: last commit 2026-05-18, latest release v0.1.9 2026-03-31, releases in last 12 months 20, open issues 166, archived no, license MIT or Apache-2.0.
   - Evidence: findings #5, #6.

OS key custody facilities (not ranked, each is the only choice on its platform):
- macOS: a Secure Enclave key with privateKeyUsage only, stored in the data protection keychain by a signed, bundled LaunchAgent that starts at login; it wraps the per-segment data keys. Prompt-free after login; not available before login or from a daemon. Evidence: #3, #4, #9, #31.
- Windows: DPAPI user scope (CryptProtectData without LOCAL_MACHINE) from a per-user logon task, optionally wrapping a key created in the Microsoft Platform Crypto Provider with no UI policy. Prompt-free after logon for the same user. Evidence: #12, #15, #20.

Rejected:
- Screenpipe as a dependency: Screenpipe Commercial License, not MIT-compatible (#2, #40). Its published numbers remain useful as cost estimates.
- Windows Hello or Hello ESS gated keys, and the Recall enclave design: every use needs a PIN or biometric gesture, which fails unattended operation (#17, #22, #29). The injection finding (#14) also shows the enclave does not protect data after the user has authenticated.
- BGTaskScheduler for macOS background scheduling: not available on native macOS (#47).
- DPAPI-NG for this product: its principals are domain groups and web credentials; LOCAL=user adds nothing over DPAPI on a single laptop (#30, #33).
- Rewind as a reference design: discontinued (#23).

## Unknowns
- Whether a macOS LaunchAgent can use a Secure Enclave key while the screen is locked after reboot (kSecAttrAccessibleAfterFirstUnlock on macOS). Checked: Apple keychain data protection page says Data Protection is not used directly on macOS (#9); TN3137 covers login context only (#3). Would settle it: a ten-line test from a bundled LaunchAgent with the screen locked.
- Whether a TPM key from the Microsoft Platform Crypto Provider can be created with no PIN policy for a per-user logon task. Checked: #12, #15 say nothing about UI policy. Would settle it: a test of NCryptCreatePersistedKey with no NCRYPT_UI_POLICY, or the NCryptSetProperty docs.
- CPU, battery share and storage of multi-week capture on a given laptop. Checked: Screenpipe README and FAQ (#2, #40), Recall storage caps (#16); all self-reported, no setup, no battery figures. Would settle it: a measured run of the chosen capture pipeline under the owner's observation window.
- APFS and NTFS TRIM timing and SSD residue after file deletion. Checked: web results were vendor and recovery-firm blogs, no Apple, Microsoft or NIST primary on timing. NIST SP 800-88 Rev. 2 (#19) covers sanitization methods; a read of its cryptographic erase section would settle what the standard accepts.
- An OS API that lists what an app stores for a user-visible inventory. Checked: Windows ApplicationData (#18) reaches only the app's own folders; Apple privacy manifest page could not be read without JavaScript. Would settle it: Apple's privacy manifest documentation (developer.apple.com/documentation/bundleresources/privacy-manifest-files) and the Windows Settings storage internals.
- Rewind's own storage and compression numbers. Checked: rewind.ai returned 403 and the app is discontinued (#23); only reviews remain. Not worth settling.
- Whether Microsoft changed Recall after the April 2026 injection report. Checked: #13, #14; no Microsoft statement of a design change found.
