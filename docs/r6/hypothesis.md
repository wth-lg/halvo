# The owner's hypothesis, cell by cell

The owner wrote that for the landlord tasks open-source models "will not differ much in performance from the top OpenAI or Anthropic reasoning models". This run found that no row of its three research reports scores a utility-portal sign-in with a second factor, a real payment, a lease edit or a tenant-application review at any tier, and that the nearest thing, a verification code sent by mail in one benchmark's list of calls, has no score (r2 #78). So the hypothesis is untested on every landlord task, and each status below rests on a nearby task.

A reference such as (r1 #106) names row 106 of research report r1 of the routing run; r2 and r3 are its other two reports. The list at the end of this page gives each row's source, date and link. Every figure below is a figure of its row, in points of that table's score.

## How a cell is read

- The categories fall into three groups by their task. The web tasks (`utility_bill_payment`, `shop_order`) are near multi-step work on web sites or in web apps. The office tasks (`email`, `spreadsheet_fill`, `calendar_cleanup`) are near multi-step work in mail, sheet, calendar or business apps. The five others are near only a task of their own kind. The categories of a group hold the same cells.
- A table counts for a cell when it scores, in one stated setup, a model of the class and a top model of OpenAI or Anthropic of its time on a task near the category's group, and is neither the table of a model's own maker nor one person's rerun.
- The laptop-size class holds models of 9B parameters or fewer, the largest hosted class the strongest open-weight model of a table, and the cheaper hosted class its low-cost open-weight models.
- The reference of a table is its best OpenAI or Anthropic model, because the owner's sentence names those two makers. A class is read by its best model in the table, and the gap is the reference less that model.
- The word is `supported by proxy` for a gap of 10 or less, `contradicted by proxy` for a gap over 20, and `mixed` between. Where the counted tables of a cell, or two scorings of one table, give different words, the cell is `mixed`. A table that scores an earlier model of the class than another counted table of the cell is a limit and gives no word. The word is `untested` when no table counts.
- A cell of the first three classes holds its word, the reference and the model behind the gap, then the rows that count, then its limits: among them every table that bears on the cell and does not count. A cell of the closed class holds `reference` where a table of its row counts, and `untested` otherwise.

- A general agent set of 233 tasks, which counts for no group, puts a 9B model at 33.8 on its text tasks and 33.9 on its multimodal tasks against 80.3 and 78.0 for GPT-6-Astra, and a 27B model at 61.8 and 55.1, both served locally at FP16 with a 32K context on one 96 GB GPU. On its multimodal tasks the 9B model has 62.5 against 70.0 on 20 single-step tasks and 16.2 against 67.6 on 25 multi-step tasks with tools (r1 #70).
- On long desktop computer use Kimi 2.6 and MiniMax M3 each scored 4.6 percent, and a third open model 2.8, against 18.52 percent for Claude Opus 4.8 with the same tool setting. The paper names the three as open source only as a group (r1 #66, #98; r2 #54).
- A skill library that GPT-4o induced from successful traces lifts a 9B model from 54.5 to 98.5 percent on household tasks, and on web tasks from 21.2 to 23.9 and a 4B model from 10.1 to 18.7, against 37.0 for GPT-5-chat with the same skills (r1 #103). The library was induced by a closed model, and the authors give no run count.
- The tenant application needs a legal read before any proposal covers it: which laws apply when tenant-application data goes to a processor is an open question of report r3, which did not look into it.
