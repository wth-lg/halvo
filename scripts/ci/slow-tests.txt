# The slow tests: what 12-test skips in the merge gate (sh scripts/ci/run-ci-d.sh <job> --merge-gate),
# and the group in which each of them runs in a slice (scripts/ci/slices.txt, the kind tests).
#
# A line is one of six words, then a name, the capital letter of a group, and a note:
#   targets <package> <group> [<job>]      every test target of that package; its unit tests stay
#   target <name> <group> [<job>]          every test target of that name, in whatever package has one
#   units <package> <group> [<job>]        the unit tests of that package's library and binaries
#   test <part> <group> <package> [<job>]  every test whose name holds the part (cargo test -- --skip
#                                          <part>); the group runs the part in the unit tests of that
#                                          package
#   doc-tests <group>                      the doc-tests of every package
#   kept <package> <part> [<job>]          the merge gate runs the unit tests of that package whose name
#                                          holds the part, although a units line names the package; no
#                                          group. 12-test prints how many such tests passed and fails
#                                          when none did
# A job, macos or windows, limits a line to the merge gate of that job. On a targets, target, units
# or test line, that job's gate skips what the line names and the other job's gate runs it; the group
# runs it wherever scripts/ci/slices.txt runs the group, so give such a group a tests line in the
# slices of that job alone. There a word of the letters a to z alone is a job word, and 12-test
# refuses one that is neither macos nor windows, so the note of such a line begins with a digit or
# another sign. On a kept line, that job's gate alone runs the part and the other job prints
# kept_not_counted (so the note of a kept line never begins with the word macos or windows).
# The merge gate keeps the unit tests of every package that no units line names, and the test
# targets of the packages that hold a core promise (scripts/ci/core-promises.txt): halvo,
# halvo-capture, halvo-derived, halvo-learn, halvo-learn-gate, halvo-learn-store, halvo-redact,
# halvo-route, halvo-route-gate and halvo-route-wire. In those, a target or a group of unit tests
# is here when it took about 6 s or more in one of the two jobs.
