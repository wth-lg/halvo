# The slow tests: what 12-test skips in the merge gate (sh scripts/ci/run-ci-d.sh <job> --merge-gate),
# and the group in which each of them runs in a slice (scripts/ci/slices.txt, the kind tests).
#
# A line is one of six words, then a name, the capital letter of a group, and a note:
#   targets <package> <group>      every test target of that package; its unit tests stay
#   target <name> <group>          every test target of that name, in whatever package has one
#   units <package> <group>        the unit tests of that package's library and binaries
#   test <part> <group> <package>  every test whose name holds the part (cargo test -- --skip <part>);
#                                  the group runs the part in the unit tests of that package
#   doc-tests <group>              the doc-tests of every package
#   kept <package> <part> [<job>]  the merge gate runs the unit tests of that package whose name holds
#                                  the part, although a units line names the package; no group. 12-test
#                                  prints how many such tests passed and fails when none did; a part
#                                  whose tests one job alone has is followed by that job, macos or
#                                  windows, and the other job runs it and does not count it (so the
#                                  note of a kept line never begins with the word macos or windows)
