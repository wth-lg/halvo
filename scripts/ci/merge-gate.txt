# The merge gate: the checks that a push and a pull request run.
# sh scripts/ci/run-ci-d.sh <job> --merge-gate runs the lines of its job and no self-test. Before them
# it runs the red control, scripts/ci/red-control, a check that always fails, and goes on only when
# the driver's run of it failed.
# A line is a job, macos or windows, a blank and the name of a check of that job.
# Every other check that CI runs, and every self-test, stands in a slice of scripts/ci/slices.txt.
# The run of both jobs ends in under 1,200 s. Before you add a line, name the seconds of the check
# in that job and what it protects; scripts/ci/README.md, The merge gate, holds the measured seconds.
# 11-clippy stands in the windows list alone; the lint of the macos job runs in the slice wed2.
# Tests of code that is the same on both systems run in the windows job alone, because a Mac job is
# the slower and the scarcer one (r8 cut-2): a check that reads the same files and runs the same code
# on both systems stands in the windows list alone.
