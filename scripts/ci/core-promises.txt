# The checks and the tests that hold one of the six core rules of Halvo, and where each runs.
#
# A line is: <promise> <kind> <name> <place> <clause>
#   promise  secure-input  the secure-input guarantee
#            store         the key and the deletion of the store
#            capture       what the capture takes: private windows, listed apps, the screen
#            billing       a billing amount
#            egress        nothing captured leaves the machine: what a binary links or sends
#            licences      MIT-compatible licences only
#   kind     check   a script of the table, by its name
#            target  a test target, as <package>/<target>
#            units   unit tests, as <package> for all of them or <package>::<module path> for a group
#   place    gate       the merge gate runs it, on every push and pull request (scripts/ci/merge-gate.txt;
#                       for a test: 12-test runs it in the form of the merge gate)
#            scheduled  a slice runs it, once a week and in a run by hand (scripts/ci/slices.txt; for a
#                       test: 12-test runs it in the group form, by its group in scripts/ci/slow-tests.txt)
#   clause   for scheduled, first the slice (mon, tue, wed, wed2, thu, fri, sat or sun), then the job when the
#            jobs differ, then the reason; for gate, the job when one job alone has the check or the group
#
# A check has one line for each place: a check that is in the gate of one job alone has a second
# line, scheduled, for the other job. A line moves to scheduled only with its reason. A test target
# under about 6 s stays in the gate, and so does a check under about 60 s where the job has room.
# What holds the rule on egress in the gate: 21-tree-bans in both jobs, 60-r6-egress in the macos job
# and the tests of 12-test; 10-egress, 80-r6-absent, 38-app-engine-routes and 20-r6-gateway run in
# slices. Before a release the eight slices are run by hand at the commit of the release
# (scripts/ci/README.md, The slices). The seconds of a check are those of the pull request run
# 44877874023, which ran the whole table, unless the clause names another run; those of a group of
# unit tests are the gaps before its lines in a job of the push run 44893237714.
# The list is made by reading check rules and test names; no check reads it.
