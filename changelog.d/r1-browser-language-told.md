- Changed: (capture run, r1 browser-language-told) On a Mac, Halvo tells the language of Chrome and of Edge from the browser itself. It reads the language files inside the browser's own app from the disk, asks macOS for the list of what the browser holds open and about each open file, and takes of each answer the file's device and inode alone, to find which of those language files it holds; it asks for no name of an open file and keeps none of the numbers. It no longer reads the language settings for this. A Chrome or Edge that was open before Halvo started, or that runs its first session after its install, has its titles recorded where it shows English and lies in an Applications folder, without being opened again.
- Fixed: (capture run, r1 browser-language-told) On a Mac, Halvo records no title of a Chrome or Edge that was started in another language by the argument -AppleLanguages. Before, it read such a browser as English where the language settings read English.
