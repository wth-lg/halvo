- Changed: CI builds the dev and test profiles with `limited` debug information, debug information without type or variable-level information, in place of full: the block `env:` at the top of `.github/workflows/ci.yml` sets `CARGO_PROFILE_DEV_DEBUG` and `CARGO_PROFILE_TEST_DEBUG`, so that the Rust cache of each job gets smaller. The two values enter the key of the Rust cache, so the first runs after the change restore no cache. The release profile and every build outside CI keep their settings.
