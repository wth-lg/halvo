- Added: (capture run, package-runner) The runner of an agent, `halvo-runner`, ships beside the app's executable: `packaging/helpers.d/halvo-runner` names it, so `npm run tauri build -- -- --locked` builds it by a cargo call of its own, with no feature and no test target, and puts it in `Halvo.app/Contents/MacOS/` beside `halvo` and, on Windows, in the installer beside `halvo.exe`. The checks 70-package-macos and 70-package-windows read it there as they read every helper, by `62-build.sh --files`, which starts it with `--version`.
- Changed: 70-package-macos fails when `Halvo.app/Contents/MacOS` holds an entry other than `halvo` and the helpers of `packaging/helpers.d`, and 70-package-windows fails when a file whose name ends in `.exe` stands beside `halvo.exe` and is neither a helper nor the `uninstall.exe` of the installer template.
