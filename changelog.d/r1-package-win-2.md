- Added: (capture run, package-win cut 2) The Windows installer stops Halvo before an uninstall and before an install over a copy: `halvo-capture ctl stop`, then the end of the app, then a wait of at most 20 s for `halvo.exe` and each helper; where a file is still held it stops with one sentence and removes or installs nothing. Where the uninstaller's box is ticked, or a silent uninstall gets `/DELETEALL`, it first deletes everything by `halvo-capture --delete-all --data-dir` on the directory that the new form `halvo-capture --default-data-dir` prints, goes on only at exit 0, and then removes the folder of Halvo's window. The uninstall takes the Run value `Halvo` away, and an install without the WebView2 runtime says so in one sentence, into `WEBVIEW2-RUNTIME-MISSING.txt` for a silent install. Check 70 installs, starts, stops, installs over a held copy and uninstalls with `/DELETEALL` on a GitHub-hosted runner.
- Changed: The uninstaller's box reads "Also delete everything that Halvo has stored on this computer", and a silent uninstall without `/DELETEALL` deletes nothing that Halvo stored.
