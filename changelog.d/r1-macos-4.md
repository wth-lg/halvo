- Added: (capture run, macos-4) The macOS sources record through the content floor: one keystroke record with its class (printable, editing, navigation, enter, tab, shortcut or other) for each key-down transition and a modifier's press, made only at the release of the hold with the clearance that the check gave at the key's arrival, one click record for each button press, one record with a count for each of scroll, drag and move in each 1,000 ms interval that had activity, except the interval that is open at a stop, whose folded events are counted in pointer_dropped_at_stop and leave no record, a title record with capped text, whose cut is true also when the 1,024-unit read cut the title, each time the 400 ms poll finds a new title of the focused window, and the held run's six values counted by phase.
- Changed: (capture run, macos-4) The macOS event tap sits at the session location, asks for the key types only while key_class is on and for the mouse types only while pointer_class is on, and is not made with both off; a key up, an automatic repeat and a released modifier are no longer recorded, and Caps Lock counts at each press.
- Security: (capture run, macos-4) No macOS keystroke or click record leaves for a listed app or a process under the exclusion root in front (a click is decided on the front read at the click), a fold record leaves only for a kept app in front at its interval's end and counts only motion that arrived while the poll's last reading was a kept app, no title that was asked for, read or answered under an active secure-input reading is stored, the title of a private window of Chrome, Edge, Firefox or Safari makes no record, a key older than 250 ms counts in late_events and is not recorded, and an input start with key_class on fails with the permission error when the system refuses the key events (the preflight is asked only while key_class is on).
