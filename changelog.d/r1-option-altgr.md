- Changed: On a Mac a sign that you type with Option, or with Option and Shift, such as the at sign, the euro sign or a bracket on many keyboards, now counts among the letters, digits and signs and is no longer noted as a shortcut, so where Halvo notes keys before a program has moved to its password field, it no longer shows where in a password such a sign stands. A key pressed with Option and Command or Control stays a shortcut, and so do an arrow, Backspace, Return and Tab with Option. Halvo never reads which sign a key types. On Windows nothing changes: a key pressed with AltGr is not noted there.
