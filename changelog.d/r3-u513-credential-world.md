- Security: A page's script can no longer take the credential mark off a password field or put one on a plain field: the executor keeps and reads the mark in a script world of its own.
- Changed: The executor reads a control in a script world of its own. A field that a page moved in from another document, of which that world holds no object yet, is read as what it is: a password field is a credential field by its type, and a plain field is no credential field and can be typed into, where it read as a credential field before. A value that a page's own script keeps as a property of an element, such as a custom element that defines `value`, reads as empty, so a condition `value_is` on it fails; an input, a textarea and a select read as before.
