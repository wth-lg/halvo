- Changed: On Windows `halvo-capture --delete-all --data-dir DIR` now deletes everything with no capture service running, in a release build as in a debug build, where it answered usage (exit 64) before; so Delete everything on Windows no longer needs the running service. It has the words and the exits of a Mac: `data_dir=` and the `deleted` line on standard output and exit 0 once nothing of the store, its key, its root and the registry's rows stands, or the busy line and exit 75 with nothing deleted while a service holds the directory. The delete first takes the program out of Windows Error Reporting, as every Windows run does, then opens the store under DPAPI, whose own delete runs before the delete on the directory. Where Windows refuses that exclusion, a line on standard error says so, and the delete opens no store, unprotects no root and unwraps no key: the store goes by the delete on the directory alone, and the `deleted` line reads `segments_shredded=unknown keys_destroyed=unknown`.
