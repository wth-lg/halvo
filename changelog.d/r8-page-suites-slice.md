- Added: (CI-time run, page-suites-slice) The check `scripts/r4/ci.d/30-r4-page-suites.sh` runs the three page suites of the agents page, `ui/tests/r4/agents/test.mjs`, `ui/tests/r4/confirm/test.mjs` and `ui/tests/r4/needs/needs.test.mjs`, headless and at the same time, in the browser that `tools/r4-page/browser.txt` names for the runner (WebKit in the macos job, Chromium in the windows job), after `tools/r4-page/fetch.sh` has fetched that browser and the tool's packages by their pinned hashes. It reads each suite's count line and fails when a suite fails, runs no test or prints no count line, or when the fetch fails. It stands in no slice and in no line of the merge gate: a run by hand with the input `checks` runs it, `gh workflow run ci.yml -R wth-lg/halvo --ref <ref> -f checks=30-r4-page-suites`.
