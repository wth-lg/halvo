- Changed: (capture run, macos-4b) On a Mac the titles of Chrome and Edge windows are recorded again, but only for a browser process that runs in the localization `en` of its bundle, which the system's own function picks from the browser's AppleLanguages value or else the person's global list, each read after a synchronize call; whose bundle lies under /Applications, /System/Applications or the person's own Applications folder; and that started, by the machine's tick count, after the capture source began and after the last change of either value that a reading saw. Under any other language, where the value that the browser goes by cannot be read, and for Safari, Firefox and every other browser, no title is read. A browser is also every app whose place the system lists among the handlers of https links, set against the place of the app in front with no file read; where that list was read, an app under a whole domain of the closed list (org.mozilla., org.torproject., org.chromium.) that no full id of the list names is a browser only when the list names its place, so Thunderbird's titles are recorded again.
