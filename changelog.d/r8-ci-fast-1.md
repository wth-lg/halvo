- Changed: A push and a pull request now run the merge gate in place of the whole table of CI checks, so that a CI run ends in under 20 minutes. `scripts/ci/merge-gate.txt` names the checks of each job, `sh scripts/ci/run-ci-d.sh <job> --merge-gate` runs them, and 12-test skips there the test targets, the unit tests, the test names and the doc-tests that `scripts/ci/slow-tests.txt` lists. The whole table, with every self-test, runs on the Sunday schedule and in a run by hand (the event workflow_dispatch), where 30-mutants also takes its rotation of rows at refs/heads/main. `scripts/ci/core-promises.txt` names the checks and the tests of the six core rules with the place of each, and a job of the merge gate has its own limit, the key ci_gate_job_timeout_min of `docs/baseline/r1-gate-bounds.txt`.
