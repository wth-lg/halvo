- Security: On Windows, at every start of Halvo, with --background too, the app removes the crash reports of the web view of its own window, which can hold what the window showed, before it makes the window; where one stays, the page says "Halvo could not remove a crash report of its own window in {folder}. The report can hold what the window showed. Remove it yourself." The end of a whole Delete everything removes them from the same folder, which the app names itself, so they also go where the web view could not name its folder.
- Added: halvo.exe --remove-crash-reports removes the crash reports of the web view of Halvo's own window with no window and no web view, for the uninstaller: it prints one line, `crash_reports folder=<path> removed=<n> left=<n>`, and exits 0 where nothing was there or every file went, and 1 where one stays.
