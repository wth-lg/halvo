- Changed: (CI-time run r8, one-os) A run by hand of the workflow `ci` takes the input `os`, `both`, `macos` or `windows`, with `both` where it is not given, and starts the job of each system that it names: with `os` set to one system, a run by hand of that system's checks no longer starts the other system's job, which ran none of the named checks and took a runner. With `os` set to `windows`, the steps of the macos job that bear no condition (Commit messages, Changelog, Line endings and Own-source reads among them) no longer run in that run by hand; no gate reads a run by hand. A push run and a pull request's run start both jobs as before, and 17-workflow-lint pins each job's condition.
