- Changed: (CI-time run r8, one-os) A run by hand of the workflow `ci` takes the input `os`, `both`, `macos` or `windows`, with `both` where it is not given, and starts the job of each system that it names: with `os` set to one system, a run by hand of that system's checks no longer starts the other system's job, which ran nothing and took a runner. A push run and a pull request's run start both jobs as before, and 17-workflow-lint pins each job's condition.
