- Added: On Windows, when Halvo stops because its start fails or because its main thread panics, it shows one message of the system, with the title "Halvo", the error icon and one OK button: "Halvo stopped because of an error. Open Halvo again.", and nothing of the fault. The message comes once, and only where Halvo has no standard error, as for a start from the Start menu, a shortcut or a login item; where standard error is given, Halvo writes its line there as before and shows no message. A panic of another thread shows nothing. The check scripts/r1/ci.d/35-app-windows-memory.sh starts the built app on a Windows runner on a data folder that is not set up, waits 60 s and prints the summed peak working set of halvo.exe and of its msedgewebview2.exe processes, with no bound yet, in the windows job of the slice mon; it fails when no halvo.exe of that folder runs, or no msedgewebview2.exe runs below it.
- Fixed: On Windows, halvo.exe --version started from a console prints the version in that console: where the app has no standard output, it attaches to the console of the program that started it before it prints.
- Security: On Windows the web view of Halvo's window sends no crash report to Microsoft: the app gives it an environment of its own with custom crash reporting on, with the browser arguments, the language, the extensions and the scroll bar of before, on the same data folder. After a crash of the web view its dump stays on the computer, in the web view's own folder beside Halvo's data folder.
