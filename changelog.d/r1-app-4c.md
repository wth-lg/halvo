- Added: On Windows the press on Start writes the value Halvo under the Run key of the person's own registry (HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run), the app's own path in quotes with --background, so that Windows starts Halvo hidden at each logon; nothing writes it before that press, and a run with --data-dir never writes it. Each start of an app that has the consent (its data folder holds daemon-state.json) reads the value and writes it again where it differs or stands not, before the window can open. Where the write at the press, or a read or a write at a start, fails, the page says that Halvo could not set itself to open when you log in, and never that the start at logon is off. A start that finds no consent takes the value away; a removal that fails is one line on the app's standard error. A Delete everything keeps the consent, so Halvo goes on starting at each Windows logon.
- Changed: On Windows, while agents need the person, the tray's tooltip keeps its own words for the capture state and puts "Agents that need you: N" on a line after them, so that the tooltip still says the state where Windows shows no tray title; the Mac keeps the count in its title as before.
- Fixed: On Windows the tray's line for a window that cannot open no longer names macOS; it reads "Halvo's window cannot open right now. You can still pause or resume here. Quit Halvo and start it again." The Mac keeps its own line.
