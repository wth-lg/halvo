- Fixed: The supervisor library gives every runner its caller's data directory as `--data-dir`, and a file step of a runner without it fails with `step_failed`, so the runner now locks under its caller's data directory alone; before, a runner and a caller that opens the locks under its own data directory would each have held a lock of their own for one folder.
- Changed: `Confirmer::answers` returns each answer with the id of its effect; the library releases a decision only when the ids match the asked effects in their order, and rejects every effect of a request on any mismatch.
