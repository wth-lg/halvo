W1, the row with typing on:
Halvo records a key only when, just after you press it, the text changes in a field that Windows does not report as a password field. It records when you pressed the key, in which app, and what kind of key it was: a letter, digit or sign, or a delete key. It never records which letter, digit or sign. Halvo can tell this only in Chrome and Edge and in the plain text boxes of classic Windows programs: in every other program it records no key. It records no Return or Enter, no Tab, no arrow key, no Escape and no shortcut.

L0, where no key is noted (behind W1's sentence there):
On Windows, Halvo records no key in a program whose text box is not the plain one of a classic Windows program: a word processor or another program with a rich text box, a program built with a newer Windows framework, a terminal, a program built on Chromium under its own name, and Firefox.

L1, the length:
On Windows what Halvo keeps shows at most how many letters, digits and signs you typed in such a field: a sign typed with AltGr and the repeats of a held key are not noted.

L2, the two costs:
On Windows, in the plain text box of a classic program, after Tab, an arrow key, Escape, a shortcut, a key that puts an accent on the next letter, or an Enter that makes no new line, Halvo leaves out letters that you type next, until you pause for a quarter of a second: at an ordinary typing speed all of them, at a very fast one only the last before the pause, at a slow one only the first. This does not happen in pages in Chrome and Edge. Where a password manager fills a field, or a page clears its password box, while you type in another field, Halvo leaves out what you type for about a third of a second.

L3, the visible password, both systems (ONE sentence pair, the Mac named in it where the file needs it):
A password that you make visible, for example with a show-password button, is typed into an ordinary text field: Halvo notes its keys like any others, when, in which app and what kind of key, never which letter, digit or sign, and so its length. Pause capture before you type a password that you can see.

L4, a box drawn as dots (added to the standing sentence on such boxes):
in Chrome and Edge, a text box that a page only draws as dots is an ordinary text field to Halvo: every key typed there is noted in the same way.
